1. 프로젝트 개요 (Overview)
프로젝트명: 콜라보레이션 응모 및 추첨 시스템(Collab Project)
개발 기간: (예: 2026.09 ~ 2026.09) / 개인 프로젝트 (1인)
프로젝트 소개:
평소 서브컬처 문화에 관심이 많았고, 어느날 인적사항을 기입해서 응모하면 추첨으로 상품을 배송해주는 콜라보 이벤트에 참여한 적이 있었음.
이 이벤트에 영감을 받아 배운 기술을 활용해보고자 생각하여 Spring Boot및 Thymeleaf 등을 활용하여 백엔드 및 프론트로 간소화된 프로젝트 화면을 구현하였음.

2. 기술 스택 (Tech Stack)
Backend: Java 17+, Spring Boot, Spring Data JPA
Frontend: Thymeleaf, HTML5, CSS
Database: H2 Database (In-Memory DB)
Tools: Git, GitHub, IntelliJ IDEA, Gradle
